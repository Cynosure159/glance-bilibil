使用方法

GET / - 获取所有 UP 主的视频汇总 HTML（供 Glance 嵌入）

GET /json - 获取所有 UP 主的视频汇总 JSON

GET /help - 本帮助说明页

参数说明

参数 默认值 说明
limit {{ .DefaultLimit }} 显示视频数量
style {{ .DefaultStyle }} 样式: horizontal-cards/grid-cards/vertical-list
mid - 临时指定单个 UP 主 UID

配置频道会在服务启动时预热，并按 refresh_interval（默认 1h）后台刷新。临时 MID 仅在访问时按需刷新。

示例

  • / - 所有 UP 主视频汇总
  • /json - 获取 JSON 格式视频汇总
  • /?limit=10&style=grid-cards
  • /?mid=946974&limit=5 - 单个 UP
